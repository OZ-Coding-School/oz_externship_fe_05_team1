# 📚 통합 교육 플랫폼(LMS) 개발 프로젝트

> 회원 관리부터 쪽지시험까지, 교육 플랫폼 운영자를 위한 통합 어드민 대시보드

---

## 📖 프로젝트 소개

> 본 프로젝트는 교육 플랫폼 운영자가 효율적으로 서비스를 관리할 수 있도록 돕는 어드민 대시보드입니다.  
> 회원 관리, 권한 설정, 쪽지시험 관리 등 교육 플랫폼 운영에 필요한 핵심 기능을 제공합니다.

## 🚀 Getting Started

### 설치

```bash
npm ci
```

### 개발 서버 실행

```bash
npm run dev
```

### Storybook 실행

```bash
npm run storybook
```

---

## ✨ 주요 기능

### 회원 관리

- 회원 등록 승인 / 반려
- 권한 관리
- 회원 상세 정보 조회 · 수정 · 삭제

### 쪽지시험 관리

- 시험 생성 / 배포 / 수정 / 삭제
- 응시 내역 조회 / 삭제

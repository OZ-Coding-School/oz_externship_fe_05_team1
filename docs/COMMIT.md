# 💬 Git 커밋 메시지 컨벤션 (Commit Message Convention)

프로젝트의 커밋 이력을 명확하고 추적 가능하게 관리하기 위해 Conventional Commits 사양을 따릅니다.

## 1. 커밋 메시지 구조

커밋 메시지는 다음 세 부분으로 구성되며, 제목과 본문 사이는 한 줄 띄어쓰기 합니다.

##### <type>(<scope>): <subject>(#<issue-number>)

### 1.1. 작성 규칙

- **제목 (Subject)**:
  - **50자 이내**로 작성합니다.
  - **소문자**로 작성합니다. (대문자 사용 금지)
  - **명령문**으로 작성합니다. (예: "추가한다" ❌ → "추가" ⭕)
  - 마침표를 붙이지 않습니다.
  - **이슈 번호**를 반드시 포함합니다. (예: `(#12)`)
- **본문 (Body)**:
  - 제목과 한 줄 띄우고 작성합니다.
  - **무엇을** 변경했고, **왜** 변경했는지 상세히 작성합니다.

### 1.2. Good/Bad 예시

| 유형                     | 예시                                                                                                                      |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------ |
| **Good (본문 있음)**     | `refactor: useFetch 훅 에러 처리 로직 개선(#30)`<br><br>`- abort시 로딩 상태를 변경하지 않도록 수정하고 strict mode 추가` |
| **Bad (규칙 위반)**      | `Docs: README.md 업데이트. (#10)` (대문자, 마침표 사용)                                                                   |
| **Bad (이슈 번호 누락)** | `feat: 위시리스트 구현`                                                                                                   |

---

## 2. 커밋 타입 (Type)

`<type>` 필드에 사용 가능한 종류와 설명은 다음과 같습니다.

| Type       | 설명 (Description)                                       | 예시 (Example)                                       |
| :--------- | :------------------------------------------------------- | :--------------------------------------------------- |
| `feat`     | 새로운 기능을 개발 (New Feature)                         | `feat(badge): StatusBadge 컴포넌트 구현(#12)`        |
| `fix`      | 버그를 수정 (Bug Fix)                                    | `fix(dropdown): aria-controls 오류 수정(#15)`        |
| `refactor` | 코드 리팩토링 (기능 변경 없이 코드 구조 개선)            | `refactor: useFetch 훅 에러 처리 로직 개선(#30)`     |
| `docs`     | 문서 수정 (Documentation)                                | `docs: CONVENTION.md에 네이밍 규칙 업데이트(#40)`    |
| `style`    | 코드 포맷팅, 스타일 수정 (포매터로 해결 불가능한 것)     | `style: 컨벤션에 맞게 변수명 isSelected로 변경(#22)` |
| `chore`    | 빌드 시스템, 라이브러리 업데이트 등 (Build/Dependencies) | `chore: ESLint 설정 업데이트(#50)`                   |
| `perf`     | 성능 개선 (Performance Improvement)                      | `perf: 이미지 로딩 최적화(#65)`                      |
| `build`    | 빌드 관련 파일 수정 (Webpack, Vite 등 설정)              | `build: vite 설정 업데이트(#70)`                     |
| `ci`       | CI 설정 파일 수정 (GitHub Actions, Jenkins 등)           | `ci: workflow 파일 수정(#75)`                        |

---
